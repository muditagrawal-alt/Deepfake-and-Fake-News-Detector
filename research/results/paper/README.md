# Paper results

Everything the revised paper reports, regenerated by `research/scripts/paper_tables.py` from
the per-item run files in `research/runs/`. Do not edit these CSVs by hand.

## Benchmarks (the ones the reviewers name)

| Benchmark | Items | Source |
|---|---|---|
| FakeNewsNet-PolitiFact | MM-Soc test split, all 102 (article + image) | Jin et al., ACL Findings 2024 release of FakeNewsNet |
| FakeNewsNet-GossipCop | 300 of the 2,672 MM-Soc test articles, stratified, seed 2026 | same |
| LIAR | 300 of the 1,283 official test statements, stratified, seed 2026 | Wang, ACL 2017 |
| FaceForensics++ c23 | 200 of the 700 official test videos (100 real, 25 per manipulation method), seed 2026 | Rössler et al., ICCV 2019 |

Item lists are fixed in `research/splits/` and were committed before any run. Subsets were used
because of API cost; intervals are reported for every number.

## Rounds

- **Round 1**: baseline engine (v3.1.4; analyse → retrieve → verify, no hand-written decision
  rules), Gemini 3.5 Flash-Lite, pinned.
- **Round 2**: enhanced engine. Enhancements were developed and checked on development splits
  only (`research/protocols/`), never on these test items. Both rounds use the same test items,
  so they are compared item by item.

"With web search" means the engine's external verification is on (fact-check websites are
excluded for the news benchmarks, whose labels come from fact-checkers); "closed-book" means it
is off.

## Files

| File | What it contains |
|---|---|
| `table1_main_results.csv` | Every run: benchmark, round, engine version, condition, accuracy with 95% Wilson interval, macro-F1 with bootstrap interval, AUC, recall per class, errors, run file, commit |
| `table2_round1_vs_round2.csv` | Same items, Round 1 vs Round 2: accuracies, difference, discordant counts, exact McNemar p |
| `table3_sota_comparison.csv` | Our numbers next to published results for the same benchmark and metric, with the reference's method, regime (zero-shot / supervised) and source |
| `table4_external_verification_ablation.csv` | With vs without web search on the same items (the paper's external-verification pillar) |
| `table5_existing_tools_same_items.csv` | Existing detectors, and v1's news model, run on exactly the same items |
| `table6_cost_and_latency.csv` | Cost in rupees and median seconds per item, per run |

Conventions: FAKE is the positive class; UNCERTAIN counts as wrong for accuracy and macro-F1;
items that failed for provider reasons were re-run and are never scored as predictions.
